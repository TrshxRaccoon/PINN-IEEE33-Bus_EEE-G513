# Temporal Convolutional Network (TCN) State Estimator

This module implements the **Physics-Informed Temporal Convolutional Network (PI-TCN)** state estimator for the IEEE 33-bus radial distribution grid. The TCN utilizes **causal dilated 1D convolutions** over historical telemetry sequences, providing **temporal dynamic inertia** that bounds estimation drift when PMU sensors experience sudden communication blackouts.

---

## Directory & File Roles

| File / Folder | Role & Description |
| :--- | :--- |
| `tcn_model.py` | **TCN Architecture Definition**: Implements the causal 1D convolutional model in `torch.float64`. Features `Chomp1d` layers for strict right-trimming (preventing future information leakage), residual temporal blocks with weight normalization and skip projections, and exponentially growing dilations ($d = 2^0, 2^1, 2^2, 2^3, 2^4$). Includes the projection head mapping sequence representation $h_T$ to 66 grid outputs. |
| `train_tcn.py` | **Core Training Engine**: Trains the PI-TCN across Clean and Augmented dropout regimes. Handles temporal sequence mini-batching, the 20% epoch $\lambda$ warm-up schedule, AC power flow physics regularization, and evaluation across all 5 test dropout levels ($10\%$ to $50\%$). |
| `make_sequential_dataset.py` | **Temporal Dataset Builder**: Converts static load-flow snapshots from `make_dataset.py` into chronological multi-step sliding windows ($T = 10$ historical time steps) for training and testing sequence models. |
| `check_spec_contract.py` | **Automated Contract Test Suite**: Validates temporal tensor shapes ($B \times 114 \times T$), strict causality (verifying that output at time $t$ does not depend on time $t+1$), double-precision compliance, and physics residual gradient backpropagation. |
| `demo_compare.py` | **Interactive CLI Demo**: Evaluates single sequential snapshots side-by-side, comparing true states against Baseline TCN and Physics-Informed TCN predictions under extreme 50% sensor dropouts. |
| `plot_results.py` | **Publication Plotting Tool**: Plots $|V|$ and $\theta$ RMSE curves versus PMU measurement coverage, demonstrating the temporal resilience of the TCN compared to memoryless feedforward estimators. |
| `snapshot_comparison.png` | **Visual Demonstration Artifact**: Visual graph generated by `demo_compare.py` illustrating voltage profiles under severe telemetry loss. |
| `data/ieee33/` | **Sequential Dataset**: Contains generated sequential multi-step files: `train.npz`, `val.npz`, `test_drop10.npz` to `test_drop50.npz`, and `meta.npz`. |
| `plots/` | **Visualization Figures**: Stores high-resolution performance plots for Clean and Augmented TCN evaluations. |
| `results_augmented/` | **Augmented Model Artifacts**: Stores trained model weights (`model_Augmented_lam*_seed42.pt`, `best_model_Augmented_seed42.pt`) and the complete benchmark evaluation (`benchmark_augmented.csv`). |
| `results_clean/` | **Clean Model Artifacts**: Stores trained model weights (`model_Clean_lam*_seed42.pt`, `best_model_Clean_seed42.pt`) and benchmark metrics under surprise blackouts (`benchmark_clean.csv`). |

## Model Specifications

* **Temporal Window Length ($T$)**: $10$ sequential steps (equivalent to a $\sim 12$-hour diurnal receptive field).
* **Input Features ($C_{\text{in}}$)**: $114$ features per time step (structured identical to the standard 5-block data contract).
* **Network Backbone**:
  * 5 Residual Temporal Blocks with dilations: $d \in \{1, 2, 4, 8, 16\}$.
  * Kernel size: $k = 3$.
  * Channel dimensions: $114 \to 64 \to 64 \to 64 \to 64 \to 64$.
  * Strict causality enforced by `Chomp1d(padding)` right-trimming.
* **Output Dimension**: $66$ outputs ($|V|_{0..32}$ and $\theta_{0..32}$ for all 33 buses).
* **Parameters**: $256{,}706$ trainable parameters ($1.97\text{ MB}$).
* **Execution Precision**: Strictly `torch.float64` / `torch.complex128`.

## How to Run

1. **Build Sequential Dataset (if not already present)**:
   ```bash
   python make_sequential_dataset.py --in_dir ../MLP/data/ieee33 --out_dir data/ieee33 --window 10
   ```
2. **Verify Temporal Contract**:
   ```bash
   python check_spec_contract.py
   ```
3. **Train Clean Baseline & Physics Models**:
   ```bash
   python train_tcn.py --data data/ieee33 --epochs 100 --bs 64 --lr 1e-3 --out results_clean
   ```
4. **Train Augmented Models (Dropout Robustness)**:
   ```bash
   python train_tcn.py --data data/ieee33 --epochs 100 --bs 64 --lr 1e-3 --aug --out results_augmented
   ```
5. **Plot TCN Performance Curves**:
   ```bash
   python plot_results.py
   ```
6. **Run Interactive Snapshot Demo**:
   ```bash
   python demo_compare.py --drop 50 --idx 0
   ```
